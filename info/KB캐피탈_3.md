# 🪙 KB캐피탈 3

# 4. 합격 자기소개서·채용 조언에서 참고할 작성 방식

## 4-1. 과거 답안의 회사 사실은 현재 자료로 바꿉니다

공개된 과거 자기소개서는 문장 구성과 경험 전개 방식을 참고할 수 있습니다. 다만 확인한 인크루트의 기업금융 샘플 안내는 2016년 채용 자료이고, 잡코리아 공개 사례도 2018년 사무 직무입니다. 이번 기업·투자금융 채용의 평가기준이나 최신 사업 방향을 보여주는 자료로 사용할 수는 없습니다. [과거 기업금융 샘플 안내](https://people.incruit.com/resumeguide/rsmpdsview.asp?pass=y&pds1=1&pds2=11&pdsno=234297), [과거 공개 자소서](https://rds.jobkorea.co.kr/starter/passAssay/view/195407)

자료가 오래되거나 전문을 확인하지 못한 경우에는 ‘합격 답안의 공통점’이라고 일반화하지 않습니다. 이번 가이드는 현재 공고·사업소개와 확인 가능한 채용 조언을 중심으로 구성합니다.

## 4-2. 첫 문장에서 질문의 중심에 답합니다

| 문항 | 첫 문장 방향 |
| --- | --- |
| 1번 | “기업·투자금융을 희망하며, 핵심 역량은 [하나]라고 생각합니다.” |
| 2번 | “저는 [최근 변화 하나]가 만드는 [금융 수요]에 주목합니다.” |
| 3번 | “제가 실천해온 TEAMS 가치는 [하나]입니다.” |
| 4번 | “[공동 목표]를 위해 저는 [역할]을 맡았습니다.” |
| 5번 | “[낯선 환경]에서 [해야 할 일]을 맡아 [학습 방법]으로 적응했습니다.” |

첫 문장에 기업 소개나 시대 배경을 길게 넣지 않습니다. 본문의 방향이 정해지면 이후의 경험과 자료를 선택하기 쉬워집니다.

## 4-3. ‘판단 기준’과 ‘수정한 행동’을 남깁니다

분석 경험의 차별점은 자료의 양이나 프로그램 이름만으로 만들어지지 않습니다.

- 왜 그 자료를 선택했는지 설명합니다.
- 어떤 기준으로 비교했는지 밝힙니다.
- 처음 생각과 다른 결과를 어떻게 확인했는지 보여줍니다.
- 그 확인으로 무엇을 바꾸었는지 설명합니다.

소통 경험도 마찬가지입니다. 대화를 많이 했다는 사실보다 상대의 우려를 알고 실행안을 어떻게 바꾸었는지가 중요합니다.

## 4-4. 금융기회는 수요·수단·조건으로 구체화합니다

2번은 다음 세 질문에 답하면 주장이 선명해집니다.

1. 어떤 기업이 어떤 이유로 자금을 필요로 합니까?
2. KB캐피탈의 어떤 금융수단으로 참여할 수 있습니까?
3. 실제 실행을 위해 무엇을 확인해야 합니까?

‘신성장산업을 지원하자’는 방향만으로는 구체성이 부족합니다. 예를 들어 데이터센터를 선택했다면 설비투자와 운영 현금흐름의 시점 차이, 해당 구조에 맞는 금융수단을 설명합니다.

## 4-5. 사실·해석·계획을 구분합니다

| 구분 | 예시 |
| --- | --- |
| 사실 | KB캐피탈이 해당 협약에 참여했다는 공개자료입니다. |
| 해석 | 관련 자금 수요를 살펴볼 협력 기반이라고 생각합니다. |
| 계획 | 입사 후 산업과 현금흐름을 검토하는 역량을 쌓고 싶습니다. |

이 세 가지가 구분되면 기업조사가 본인의 생각으로 자연스럽게 이어집니다. 협약을 성과로 바꾸거나 희망업무를 확정 배치로 바꾸는 오류도 줄일 수 있습니다.

## 4-6. 3번과 4번을 다르게 씁니다

| 문항 | 중심 질문 | 강조할 부분 |
| --- | --- | --- |
| 3번 | 나는 어떤 기준으로 행동했는가? | 가치가 선택과 행동을 바꾼 장면 |
| 4번 | 함께 목표를 이루는 데 무엇을 기여했는가? | 역할 연결과 조정·실행 |

공감을 3번으로 선택했다면 상대의 필요를 이해해 자신의 행동을 바꾼 장면에 집중합니다. 4번은 별도의 경험에서 정보 공유·역할 조정 등 공동 결과를 만든 기여를 보여주는 편이 좋습니다.

상생을 3번으로 선택하더라도 4번과 같은 팀 활동을 그대로 반복하지 않습니다.

## 4-7. AI와 디지털은 실제 수행한 방법으로 씁니다

AI 경험이 별도 필수 문항은 아닙니다. 실제 경험이 있다면 1번의 분석 방법, 3번 혁신정신, 5번 학습·적응에 포함할 수 있습니다.

| 활용 위치 | 남겨야 할 내용 |
| --- | --- |
| 1번 | 어떤 분석을 보조했고 무엇을 직접 검증했는지 설명합니다. |
| 3번 | 기존 문제와 개선 효과, 이용자의 반응을 확인합니다. |
| 5번 | 필요한 기능을 어떻게 익히고 실제 작업에 적용했는지 설명합니다. |

같은 도구 경험을 여러 문항의 중심으로 반복하지 않습니다. 도구가 결론을 내렸다는 표현보다 원자료·산식·예외를 확인하고 최종 해석한 본인의 행동을 남깁니다.

## 4-8. 면접에서 이어질 질문을 점검합니다

- 왜 은행·증권사보다 캐피탈의 기업·투자금융에 관심이 있습니까?
- 기업대출과 투자에서 회수 가능성을 보는 관점은 어떻게 다릅니까?
- 본인이 제시한 핵심 역량이 실제 경험에서 어떻게 나타났습니까?
- 이익이 증가해도 현금 부담이 커질 수 있는 이유는 무엇입니까?
- 2번에서 제시한 산업에 어떤 자금 수요와 위험이 있습니까?
- 회사가 실제 발표한 사실과 본인의 제안은 각각 무엇입니까?
- TEAMS를 실천하면서 본인이 감수하거나 바꾼 것은 무엇입니까?
- 협업과 학습에서 다른 사람의 피드백을 반영한 부분은 무엇입니까?

모든 전문용어를 유창하게 말할 필요는 없습니다. 자신이 쓴 개념과 경험을 쉬운 말로 설명할 수 있으면 됩니다.

# 5. 문항별 경험 배분 전략

## 5-1. 다섯 문항의 기능을 나눕니다

| 문항 | 중심 소재 | 다른 문항과 구분할 초점 |
| --- | --- | --- |
| 1번 | 분석·학습·직무 준비 경험 | 무엇을 할 수 있는가 |
| 2번 | 사회 변화와 기업조사 | 어떤 사업기회를 보는가 |
| 3번 | 가치에 따른 선택 경험 | 어떤 기준으로 행동하는가 |
| 4번 | 공동 과제·조직 활동 | 다른 사람과 어떤 기여를 만드는가 |
| 5번 | 낯선 업무·환경 | 어떻게 배우고 수행을 바꾸는가 |

2번에 개인 이야기를 넣지 않아도 되므로, 실제 경험은 네 문항에 분산하면 됩니다. 모든 경험이 금융과 직접 관련될 필요는 없습니다.

## 5-2. 추천하는 소재 조합

| 경험 구성 | 1번 | 3번 | 4번 | 5번 |
| --- | --- | --- | --- | --- |
| 재무·분석 경험이 강한 경우 | 기업·현금흐름 분석 | 오류 공유·원칙 실천 | 다른 역할과 공동 결과물 | 낯선 산업·도구 학습 |
| 조직·운영 경험이 강한 경우 | 자금·사업 자료 분석 노력 | 공감·상생의 선택 | 일정·역할·기준 조정 | 새로운 업무 적응 |
| 인턴 경험이 있는 경우 | 직무와 가까운 수행 경험 | 지켜야 할 기준을 실천한 장면 | 별도 프로젝트 협업 | 인턴 초기의 학습 방법 |
| 직접 금융 경험이 적은 경우 | 전공을 실제 자료에 적용 | 생활·활동 속 가치 선택 | 팀 과제·동아리·아르바이트 | 새로운 역할을 배운 과정 |

경험의 이름보다 본인의 판단과 행동이 중요합니다. 인턴이라고 반드시 좋은 사례는 아니며, 학부 프로젝트라도 실제 검증과 수정이 분명하면 사용할 수 있습니다.

## 5-3. 같은 경험을 사용해야 하는 경우

경험이 부족하다면 같은 활동을 사용하되 **서로 다른 장면과 질문**을 선택합니다.

| 사용 위치 | 같은 활동에서 선택할 장면 |
| --- | --- |
| 1번 | 자료를 분석하고 결론을 검증한 부분 |
| 3번 | 가치에 따라 선택을 바꾼 부분 |
| 4번 | 구성원의 역할과 정보를 연결한 부분 |
| 5번 | 초기에 모르는 내용을 파악하고 배운 부분 |

같은 배경·행동·성과를 그대로 반복하면 지원자의 폭이 좁게 보일 수 있습니다. 가능하면 3번과 4번은 별도 경험으로 나누는 편이 좋습니다.

## 5-4. 작성 전 빈칸형 정리표

| 정리 항목 | 작성할 내용 |
| --- | --- |
| 희망업무 | [기업·투자금융 중 관심 방향] |
| 핵심 역량 하나 | [현금흐름 분석·산업 분석·검증·소통 중 실제 강점] |
| 준비의 증거 | [문제·역할·행동·검증·결과] |
| 사회 변화 하나 | [AI 인프라·생산적 금융 등 선택 이슈] |
| 자금 수요의 대상 | [어떤 기업·프로젝트] |
| 회사의 금융수단 | [공식 소개에서 선택한 수단] |
| 확인할 조건 | [현금흐름·계약·수요·비용·회수] |
| TEAMS 하나 | [실제 경험에 맞는 가치] |
| 협업에서의 기여 | [다른 구성원의 판단·실행에 만든 변화] |
| 적응의 학습 방식 | [문서·질문·작은 실행·피드백] |

각 칸을 한두 문장으로 먼저 채우면 600자 답변을 압축하기 쉽습니다.

## 5-5. 기업조사를 반영할 위치

| 위치 | 반영할 내용 | 줄여도 되는 내용 |
| --- | --- | --- |
| 1번 역량의 이유 | 기업의 수요와 회수·거래 판단 | 회사 연혁과 전체 상품 목록 |
| 2번 회사 기회 | 실제 금융수단과 최근 연결근거 | 회사 실적과 인재상 나열 |
| 3번 가치 | 선택한 TEAMS의 행동 의미 | 회사의 최근 사업소식 |
| 4번 경험 | 필요하면 짧은 직무 연결 | 기업조사 문단 |
| 5번 성장 | 새로운 분야를 배우는 태도 | AI·디지털 사업을 억지로 연결한 설명 |

문항마다 회사 이름을 넣지 않아도 됩니다. 1·2번에서 직무와 회사를 정확히 이해한 모습이 보이면, 나머지는 본인의 경험으로 신뢰를 쌓는 구성이 자연스럽습니다.

## 5-6. 권장 작성 순서

1. 1번의 희망업무와 핵심 역량을 정합니다.
2. 3·4·5번의 경험 후보를 분리합니다.
3. 2번은 이슈를 하나 선택하고 수요·수단·조건을 정리합니다.
4. 각 문항을 700~800자 정도의 초안으로 먼저 작성합니다.
5. 배경과 반복 설명을 줄이고 판단·행동·결과를 남깁니다.
6. 실제 입력창에서 600자 이내로 조정합니다.

처음부터 600자를 정확히 맞추려 하면 핵심 행동이 빠질 수 있습니다. 먼저 내용의 인과관계를 완성한 뒤 줄이는 편이 좋습니다.

# 6. 최종 점검표

## 6-1. 회사·직무 이해

- 공고명은 2027년 신입사원 채용, 접수기간은 2026년임을 구분했는지 확인합니다.
- 기업·투자금융이 일반 분야 내 희망업무라는 점을 이해했는지 확인합니다.
- KB캐피탈과 다른 KB 계열사·다른 캐피탈사를 구분했는지 확인합니다.
- 고객의 자금 수요와 상환·회수 가능성을 함께 설명했는지 확인합니다.
- 조달비용과 자원 사용을 고려하는 관점이 있는지 확인합니다.
- 공개자료로 확인하지 않은 내부 배치·절차·상품 성과를 만들지 않았는지 확인합니다.

## 6-2. 1번 희망직무·역량

- 희망업무를 첫 부분에서 명확히 제시했는지 확인합니다.
- 핵심 역량을 하나로 좁혔는지 확인합니다.
- 그 역량이 필요한 이유를 업무의 질문으로 설명했는지 확인합니다.
- 본인의 경험에서 직접 정한 기준과 검증한 행동이 있는지 확인합니다.
- 학습·자격 이름이 구체적 경험을 대신하지 않는지 확인합니다.
- 신입으로서 활용하고 발전시킬 방향이 현실적인지 확인합니다.

## 6-3. 2번 사회 변화·기회

- 변화나 이슈를 하나로 정했는지 확인합니다.
- 누구에게 어떤 자금 수요가 생기는지 설명했는지 확인합니다.
- 회사가 실제로 취급하는 금융수단과 연결했는지 확인합니다.
- 최근 회사 관련 근거를 확인했는지 확인합니다.
- 협약과 집행·성과를 구분했는지 확인합니다.
- 성장기회를 말하면서 필요한 검증 조건도 남겼는지 확인합니다.
- 위험 설명이 기회 설명을 압도하지 않는지 확인합니다.

## 6-4. 3번 TEAMS

- 다섯 가치 중 하나만 선택했는지 확인합니다.
- 가치의 뜻보다 실제 행동이 중심인지 확인합니다.
- 그 가치를 실천해야 했던 상황이나 선택의 부담이 있는지 확인합니다.
- 본인의 행동과 결과를 구분했는지 확인합니다.
- 입사 후 어떤 구체적 강점으로 이어지는지 설명했는지 확인합니다.
- 4번의 협업 사례와 장면이 겹치지 않는지 확인합니다.

## 6-5. 4번 협업

- 공동 목표가 분명한지 확인합니다.
- 본인의 역할과 다른 구성원의 역할을 구분했는지 확인합니다.
- 함께 일해야 했던 이유나 연결 문제가 드러나는지 확인합니다.
- 본인이 공유·조정·실행한 행동이 있는지 확인합니다.
- 다른 사람의 의견을 반영한 부분이 있는지 확인합니다.
- 팀 결과와 개인 기여를 과장 없이 설명했는지 확인합니다.

## 6-6. 5번 적응·학습

- 처음에 무엇이 낯설었는지 구체적인지 확인합니다.
- 학습의 우선순위를 어떻게 정했는지 설명했는지 확인합니다.
- 문서·질문·실행·피드백 중 실제 방법이 있는지 확인합니다.
- 배운 내용을 실제 업무에 적용했는지 확인합니다.
- 피드백 이후 바꾼 행동이 있는지 확인합니다.
- 결과를 자신감보다 달라진 수행으로 설명했는지 확인합니다.

## 6-7. 사실·수치·문장

- 실적의 기간과 단위를 확인했는지 점검합니다.
- 그룹 전체와 KB캐피탈 수치를 구분했는지 확인합니다.
- 총영업이익과 영업이익, 충당금과 실제 현금손실을 구분했는지 확인합니다.
- 회사가 밝힌 사실과 자신의 해석·제안을 구분했는지 확인합니다.
- 본인이 설명할 수 있는 전문용어만 사용했는지 확인합니다.
- 모든 경험과 성과가 실제 사실에 근거하는지 확인합니다.
- 첫 문장이 질문에 바로 답하는지 확인합니다.
- 소제목과 공백을 포함한 글자 수는 실제 입력창에서 확인합니다.

## 6-8. 최종 압축 점검

| 문항 | 한 문장으로 요약할 내용 |
| --- | --- |
| 1번 | “[희망업무]에 필요한 [역량]을 [실제 행동]으로 준비했습니다.” |
| 2번 | “[변화]가 [자금 수요]를 만들며, 회사에는 [수단·조건]을 통한 기회가 있습니다.” |
| 3번 | “[가치]를 [선택·행동]으로 실천했고 [업무상 강점]으로 이어가겠습니다.” |
| 4번 | “[공동 목표]에서 [역할·조정 행동]으로 [결과]에 기여했습니다.” |
| 5번 | “[낯선 점]을 [학습·적용·피드백]으로 익혀 [수행]을 개선했습니다.” |

다섯 문장이 서로 다른 질문에 답하면서도 같은 사람의 행동 방식으로 이어지면 전체 구성이 잘 잡힌 것입니다.
