# 금융감독원 NCS 수리능력 정리

> 금융감독원 NCS 수리능력은 **자료해석 비중이 압도적**(체감 7:3 이상)이고,
> 금융·경제 통계표가 소재로 자주 나옵니다. 그 기준으로 정리했습니다.

---

# PART 1. 전체 개요

## 1. 자료해석 — 여기가 승부처

### 핵심 공식

| 개념 | 공식 | 함정 |
|---|---|---|
| 증가율(변화율) | (신 − 구) / **구** × 100 | 분모는 항상 **과거** 값 |
| 증감량 vs 증감률 | 량은 뺄셈, 률은 나눗셈 | "증가폭이 가장 큰"과 "증가율이 가장 큰"은 다름 |
| 비중(구성비) | 부분 / 전체 × 100 | 비중 ↑ ≠ 절대량 ↑ |
| 지수 | 비교시점 / 기준시점 × 100 | 기준연도가 다르면 두 지수 직접 비교 불가 |
| 연평균 증가율(CAGR) | (끝값/처음값)^(1/n) − 1, **n = 기간 수 = 연도 개수 − 1** | 2020→2024는 n=4 |
| 가중평균 | Σ(값×가중치) / Σ가중치 | 단순평균으로 계산하면 오답 |

### 실전 근사 테크닉 (요약 — 상세는 PART 2)

**① 곱셈 분해 — (1+a)(1+b) ≈ 1 + a + b**
전년 대비 10% 증가 후 다시 10% 증가 → 21% (20% 아님). 변화율이 작을 때(±10% 내외)는
단순 덧셈으로 근사하고, 오차가 선지 간격보다 작으면 그대로 씁니다.

**② 분수 비교 — 교차곱셈**
`a/b vs c/d` → `ad vs bc`. 계산하지 말고 대소만 판정.

**③ 분자·분모 증가율 비교 (가장 자주 쓰임)**
비중이나 비율이 커졌는지 물을 때:

> **분자 증가율 > 분모 증가율 → 비율 증가**

예: 매출이 5% 늘고 순이익이 12% 늘었다 → 영업이익률은 상승. 나눗셈 한 번도 안 합니다.

**④ 10%·5%·1% 쪼개기**
17,846의 23% → `1,785(10%) × 2 = 3,570`, `+892(5%) = 4,462`. 암산으로 3초.

**⑤ 유효숫자 2~3자리 절사**
선지 간격이 10% 이상이면 과감히 반올림. 단, 선지가 촘촘하면(예: 4.2 / 4.3) 정직하게
계산해야 하니 **선지를 먼저 보고 정밀도를 결정**하세요.

**⑥ 72의 법칙**
연 r%로 원금 2배 되는 기간 ≈ 72 / r. 복리 문제 검산용.

## 2. 금감원 특화 — 금융 지표

출제 소재로 표에 그대로 등장합니다. 공식을 모르면 표를 못 읽습니다.

```
단리    S = P(1 + rn)
복리    S = P(1 + r)^n
연 r%를 m회 복리   S = P(1 + r/m)^(mn)

BIS 자기자본비율 = 자기자본 / 위험가중자산 × 100
예대율          = 대출금 / 예수금 × 100
NPL비율(고정이하여신비율) = 고정이하여신 / 총여신 × 100
ROA = 당기순이익 / 총자산,   ROE = 당기순이익 / 자기자본
연체율 = 연체채권 / 총채권 × 100
```

**환율**: 원/달러 환율 상승 = 원화 **약세** = 수출 유리·수입 불리.
방향 헷갈리면 통째로 틀립니다.

**실질금리 = 명목금리 − 물가상승률** (피셔 방정식)

## 3. 응용수리 — 빈출 유형만

### 거리·속력·시간

```
거리 = 속력 × 시간
평균속력 = 총거리 / 총시간          ← (v₁+v₂)/2 아님!
같은 거리 왕복 평균속력 = 2v₁v₂ / (v₁+v₂)   (조화평균)

강물   하류 = 배 + 유속,  상류 = 배 − 유속
기차   터널 통과 이동거리 = 터널길이 + 기차길이
       마주보고 만남: 속력 합,  같은 방향 추격: 속력 차
```

### 농도

```
소금량 = 농도(%) × 소금물량 / 100
```

두 용액 혼합은 **가중평균**으로. 8%와 14%를 1:2로 섞으면 → (8×1 + 14×2)/3 = 12%.
물만 추가/증발 → **소금량 불변**을 등식으로 세우기.

### 일률

전체 일을 **1** 또는 소요일수의 **최소공배수**로 두면 분수가 사라집니다.

> A 6일, B 12일 → 전체를 12로 두면 A=2/일, B=1/일 → 함께 12/3 = 4일

### 원가·정가

```
정가   = 원가 × (1 + 이익률)
판매가 = 정가 × (1 − 할인율)
이익   = 판매가 − 원가
```

"원가의 20% 이익"과 "정가의 20% 이익"은 다릅니다. 원가를 100 또는 x로 두고 시작.

### 경우의 수·확률

```
순열 nPr = n!/(n−r)!        조합 nCr = n!/{r!(n−r)!}
원순열 = (n−1)!
같은 것이 있는 순열 = n! / (p!q!...)
중복조합 nHr = (n+r−1)C r

여사건: P(A) = 1 − P(Aᶜ)      ← "적어도 하나"는 무조건 여사건
독립시행: nCr · p^r · (1−p)^(n−r)
조건부: P(B|A) = P(A∩B)/P(A)
```

### 집합

```
|A∪B| = |A| + |B| − |A∩B|
|A∪B∪C| = |A|+|B|+|C| − |A∩B| − |B∩C| − |C∩A| + |A∩B∩C|
```

### 기타 단골

- **시계각**: 분침 6°/분, 시침 0.5°/분, **벌어지는 속도 5.5°/분**
- **수열**: 등차 aₙ = a + (n−1)d / 등비 aₙ = ar^(n−1) / 계차 안 보이면 ×2±1, 피보나치, 소수 나열 의심
- **나이·비율**: 미지수 1개로 잡히면 무조건 1개로

## 4. 시험장 운영 전략

1. **표 제목 → 단위 → 각주 순으로 먼저 읽기.** 단위(억/조, %/%p)와 각주에서 답이 갈립니다.
2. **%와 %p 구분.** 5%에서 7%로 = 2%p 증가 = 40% 증가.
3. **선지부터 스캔** → 계산이 필요한 선지가 어떤 건지 파악. 보통 5개 중 2~3개는 표만 훑어도 소거됩니다.
4. **계산량이 큰 선지는 맨 뒤로.** ①②③이 확실히 틀렸으면 ④⑤ 중 눈대중으로.
5. **버릴 문제 정하기.** 표 3개 + 그래프 붙은 세트형 마지막 문제는 시간당 기댓값이 낮습니다.
6. **"옳은 것"/"옳지 않은 것"에 동그라미.** 가장 흔한 실점 원인.

## 5. 우선순위 추천

금감원 준비라면 이 순서로:

1. **분수 비교 + 증가율 근사** — 자료해석 체감 절반
2. **가중평균** — 혼합·평균 문제 전부 커버
3. **금융 지표 공식** — 표 해독 속도
4. **거속시 / 농도 / 일률** — 응용수리 출제 3대장
5. 경우의 수·확률 — 나오면 1~2문항, 여사건만 확실히

# PART 2. 근사 계산법 심화

자료해석 근사법을 **8가지 기술**로 나눠서 정리했습니다.
이 중 ①②③만 체화해도 풀이 시간이 절반으로 줄어듭니다.

## 대원칙: 선지가 정밀도를 결정한다

근사의 목적은 "정답을 구하는 것"이 아니라 **"오답을 지우는 것"**입니다.

```
계산 전에 선지를 먼저 본다
  선지 간격이 넓다 (12% / 18% / 25%)  → 유효숫자 2자리로 과감히 절사
  선지 간격이 좁다 (14.2% / 14.7%)    → 정직하게 계산. 근사하면 오히려 틀림
  대소만 묻는다 ("가장 큰 것은")       → 나눗셈 자체를 하지 않는다
```

이 판단을 먼저 하지 않고 무작정 어림하는 게 가장 흔한 실패 패턴입니다.

## ① 기준값 역산법 — 나눗셈을 곱셈으로 바꾸기

**"A/B가 k 이상인가?" → "A가 kB 이상인가?"**

나눗셈은 느리고 곱셈은 빠릅니다. 절대 기준과 비교하는 문제는 100% 이 방식으로.

> **예제.** 총 여신 34,208억 중 고정이하여신이 7,913억이다. NPL비율이 25%를 넘는가?
>
> ❌ 7,913 ÷ 34,208 = ...
> ✅ 34,208 × 0.25 = **8,552**. 7,913 < 8,552 → **아니오**. (3초)

**확장 — 표 전체를 곱셈 한 번으로 스캔**

> **예제.** "구성비가 30% 이상인 항목은 모두 몇 개인가?" (전체 = 48,600)
>
> 48,600 × 0.3 = **14,580** 을 한 번만 계산 → 표의 모든 항목을 이 숫자와 눈으로 비교.
> 항목이 8개여도 나눗셈 0회.

**배수 판정도 동일**

> "A가 B의 4배 이상인가?" → B×4를 계산해서 A와 비교. A÷B 하지 않습니다.

## ② 증가율 비교법 — 비율의 변화 방향 판정 ★최빈출

**분자 증가율 > 분모 증가율 ⟺ 비율(분수값) 증가**

"~율이 상승했다", "비중이 커졌다", "1인당 ~가 늘었다" 류 선지는 거의 전부 이걸로 끝납니다.

> **예제.** 2023년 매출 18,400 / 순이익 1,290 → 2024년 매출 20,100 / 순이익 1,520.
> 순이익률은 상승했는가?
>
> 매출 증가: 1,700/18,400 ≈ **9%**
> 순이익 증가: 230/1,290 ≈ **18%**
> 분자 증가율이 크다 → **순이익률 상승**. 나눗셈 2번 대신 어림 2번.

**더 빠른 변형** — 분자가 20% 늘고 분모가 5% 늘었다면, 정확한 수치 없이
"분자 쪽이 압도적" 한 줄로 판정합니다.
**두 증가율 차이가 클수록 계산은 거칠어도 됩니다.**

## ③ 증분비 판정법 — 비중 변화의 초고속 판별

> **새로 추가된 몫의 비율이 기존 비율보다 크면, 전체 비율은 올라간다.**

```
기존 비중 = A/B 일 때,
증분 비중 = ΔA/ΔB 를 A/B 와 비교
   ΔA/ΔB > A/B  → 비중 상승
   ΔA/ΔB < A/B  → 비중 하락
```

> **예제.** 전체 100,000 중 서울 25,000(25%) → 다음 해 전체 110,000, 서울 28,000.
> 서울 비중은?
>
> 증분: 전체 +10,000, 서울 +3,000 → 증분 비중 **30%**
> 30% > 기존 25% → **비중 상승**
> (검산: 28,000/110,000 = 25.45% ✓)

수학적으로 `(A+ΔA)/(B+ΔB)`는 항상 `A/B`와 `ΔA/ΔB` **사이**에 놓입니다(가비의 리).
이걸 알면 구간 추정까지 가능합니다.

## ④ 변화율 대수 — 곱셈·나눗셈·거듭제곱 근사

작은 변화율(±15% 이내)끼리는 **덧셈·뺄셈으로 치환**합니다.

```
곱셈    (1+a)(1+b) ≈ 1 + a + b          [정확값: +ab 만큼 더 큼]
나눗셈  (1+a)/(1+b) ≈ 1 + a − b         [정확값: 1 + (a−b)/(1+b)  ← 이건 항등식]
제곱    (1+a)ⁿ ≈ 1 + na                 [보정: + n(n−1)/2 · a²]
역수    1/(1+a) ≈ 1 − a + a²
```

> **예제 1.** 2년 연속 8% 성장 → 1.08² ≈ 1 + 16% = **16%**
> 보정: + 0.08² = 0.0064 → **16.6%** (실제 16.64%)
>
> **예제 2.** 3년 연속 5% 성장 → 1 + 15% + 3(0.0025) = **15.75%** (실제 15.76%)
>
> **예제 3.** 매출 12% 증가, 인원 5% 증가 → 1인당 매출 증가율 ≈ 12 − 5 = **7%**
> (정확: 0.07/1.05 = 6.67%)

> ⚠️ **변화율이 20%를 넘어가면 오차가 커집니다.** 30%×30% 같은 건 그냥 곱하세요.

## ⑤ % 암산 분해 — 10 / 5 / 1 조립

임의의 퍼센트를 **10%, 5%, 1%의 합**으로 쪼갭니다.

> **예제.** 34,820의 27%는?
>
> ```
> 10% = 3,482
> 20% = 6,964
>  5% = 1,741
>  2% =   696
> ─────────────
> 27% = 6,964 + 1,741 + 696 = 9,401
> ```
> (실제 9,401.4 — 정확히 맞음)

**절반·배수 지름길**

```
15% = 10% + 그 절반
35% = 25% + 10%   (25% = ÷4)
12.5% = ÷8        37.5% = ÷8 × 3
1/3 ≈ 33.3%       2/3 ≈ 66.7%
```

## ⑥ 나눗셈 → 곱셈 변환표 (암기)

`÷1.07` 같은 나눗셈이 나오면 곱셈으로 바꿔치기합니다.

| 나누기 | ≈ 곱하기 | 나누기 | ≈ 곱하기 |
|---|---|---|---|
| ÷1.05 | ×0.952 | ÷0.95 | ×1.053 |
| ÷1.1 | ×0.909 | ÷0.9 | ×1.111 |
| ÷1.15 | ×0.870 | ÷0.85 | ×1.176 |
| ÷1.2 | ×0.833 | ÷0.8 | ×1.25 |
| ÷1.25 | ×0.8 | ÷0.75 | ×1.333 |
| ÷1.5 | ×0.667 | ÷1.4 | ×0.714 |

**패턴**: `÷(1+a) ≈ ×(1−a+a²)`. ÷1.06 → ×(1−0.06+0.0036) = ×0.944 (실제 0.9434)

## ⑦ 오차 방향 통제 — 부등호 확정법

부등호만 판정하면 될 때, **오차가 한 방향으로만 나도록** 반올림합니다.

```
A/B 의 안전한 상한 → 분자는 올리고, 분모는 내린다
A/B 의 안전한 하한 → 분자는 내리고, 분모는 올린다
```

> **예제.** 7,913 / 34,208 이 20%를 넘는가?
>
> **하한**으로 잡는다: 7,900 / 34,300 → 34,300 × 0.2 = 6,860 < 7,900
> 최소값조차 20%를 넘음 → **넘는다 확정**

이 방법의 진짜 가치는 **"판정 불가"를 스스로 알려준다**는 점입니다.

> 위 값이 30%를 넘는지 물으면?
> 상한 8,000/34,200 = 23.4%, 하한 7,900/34,300 = 23.0% → 둘 다 30% 미만, **확정**
>
> 반면 23%를 넘는지 물으면 상한·하한이 23%를 사이에 둠 → **근사 실패, 정밀 계산 필요**

## ⑧ 증가율 역산 — 10% 눈금자

증가율을 구할 때 나눗셈 대신 **원값의 10%를 눈금자로** 씁니다.

> **예제.** 18,472 → 21,905. 증가율은?
>
> ```
> 차이 = 3,433
> 18,472의 10% = 1,847  ← 눈금자
>              20% = 3,694
> 3,433은 3,694보다 조금 작다 → 20% 살짝 미만
> 1,847 × 1.8 = 3,325 / × 1.9 = 3,509
> 3,433은 그 사이 → 약 18.6%
> ```
> (실제 18.58%)

선지가 `15% / 19% / 24%`처럼 벌어져 있으면
**"3,694보다 작으니 20% 미만"** 한 줄로 끝납니다.

| 분수 | 값 | 분수 | 값 | 분수 | 값 |
|---|---|---|---|---|---|

## 두 분수 직접 비교 — 3가지 무기

### (a) 교차곱셈 — 두 개만 비교할 때

```
a/b vs c/d  →  ad vs bc
```

### (b) 앵커 경유 — 3개 이상 정렬할 때

1/2, 1/3, 1/4 같은 기준분수를 잡고 각각을 위/아래로 분류합니다.

> 5,120/14,900 vs 4,830/15,200 중 큰 것은?
>
> - 14,900 ÷ 3 = 4,967 < 5,120 → 첫 번째는 **1/3 초과**
> - 15,200 ÷ 3 = 5,067 > 4,830 → 두 번째는 **1/3 미만**
>
> → 첫 번째가 크다. 나눗셈 없이 끝.

### (c) 배율 눈대중 — 분모끼리 몇 배 차이인지 먼저 보기

> 3,200/9,800 vs 6,100/21,000
> 분모는 약 2.14배, 분자는 약 1.91배 → 분모가 더 많이 커짐 → **두 번째가 작다**
> (실제 32.7% vs 29.0% ✓)
