## 공통 시간 전략 (이게 제일 중요)
- **1문제 상한 시간을 정하고 넘기기**: 의사소통 60~70초, 수리·문제해결 90초. 넘으면 문제번호에 표시하고 다음으로. 돌아올 시간이 없어도 괜찮다는 전제로
- **영역 안에서 순서 바꾸기**: 이론·짧은 지문 문제 먼저, 계산 많은 자료문제·긴 조건문제는 뒤로
- **OMR은 페이지 단위로 마킹**: 마지막에 몰아서 하다 시간 초과되는 게 가장 흔한 사고
- **과락은 총점 90점의 40%(36점)**: 수리를 다 맞힐 필요 없음. 의사소통·문제해결에서 안정적으로 챙기고 수리는 "확실한 것만"
- 모의고사 후 오답은 반드시 3종으로 분류: ①몰라서 ②시간 없어서 ③실수. ②③이 대부분이면 실력 문제가 아니라 전략 문제라는 뜻

## 의사소통능력 (6유형)

| 유형 | 접근법 | 함정 |
|---|---|---|
| 문서 내용 이해 | 선택지 먼저 읽고 키워드 표시 → 지문에서 해당 위치만 찾기. 지문 정독 금지 | 주체·수치·시점 바꿔치기, "항상/모든/만" 같은 극단 표현 |
| 문단 나열 | 첫 문단 후보 찾기(지시어·접속사 없는 일반 진술) → 첫 문단만 확정해도 선택지 절반 소거. 접속사(그러나/따라서/예를 들어)와 지시어(이는/이러한)로 연결 | 마지막 문단을 첫 문단으로 착각 (결론형 문장) |
| 내용 추론 | "추론"이지만 사실상 지문 근거 찾기. 지문에 없는 상식·배경지식으로 고르면 오답 | 정도 표현 강화(가능하다→반드시), 인과 뒤집기 |
| 글의 주제·제목 | 첫 문단과 마지막 문단, 역접 접속사("그러나/하지만") 뒤 문장 집중 | 예시 내용을 주제로 고르기, 너무 넓거나 너무 좁은 선택지 |
| 빈칸 삽입 | 빈칸 앞뒤 문장 관계(원인→결과, 대조, 예시, 요약) 먼저 파악 → 선택지 대입 후 앞뒤 흐름 확인 | 내용은 맞지만 연결어가 어긋나는 선택지 |
| 경청·의사소통 | 암기형(경청 방해요인, 문서 종류별 특징, 의사소통 유형). 책 이론 파트 1회독으로 충분 | 시간 쓸 유형이 아님. 여기서 아낀 시간을 독해에 |

## 수리능력 (5유형)

| 유형 | 접근법 | 함정 |
|---|---|---|
| 응용 수리 | 공식 유형(소금물·속력·일률·경우의 수·확률) 공식표 1장 정리. 미지수 세팅 후 90초 안에 안 풀리면 컷. **선택지를 대입해서 역산**하는 것도 정식 전략 | 단위(분↔시간, m↔km) 변환 누락 |
| 통계 분석 | 평균·중앙값·가중평균·비율은 계산, 분산·표준편차는 **크기 비교로만** 판단(직접 계산은 시간 낭비) | 평균 변화 문제에서 인원수(가중치) 무시 |
| 자료 이해 | 표를 보기 전에 **제목·단위·기준연도·주석**부터. 선택지 하나씩 표와 대조, 판단 즉시 O/X 표시 | 증감률 vs 증감량, 비율 vs 절대값, "비중"과 "금액" 혼동 |
| 자료 계산 | **어림산**이 핵심: 유효숫자 2~3자리로 자르기. 선택지 간격이 넓으면 어림, 좁으면 그 문제만 정확 계산. 분수 비교는 분모·분자 증가율 비교로 | 필요 없는 셀까지 다 계산하기, 백분율(%)과 퍼센트포인트(%p) 혼동 |
| 자료 변환 | 표→그래프 선택지 검증은 **눈에 띄는 값 2~3개(최대·최소·0·역전 지점)만** 확인해서 소거. 전부 계산하지 않음 | 축 스케일·단위 바꿔놓기, 항목 순서 바꿔놓기 |

수리 한 줄 요약: **정확히 푸는 과목이 아니라 빨리 걸러내는 과목.** 계산 전에 "이 문제는 어림으로 되나?"를 먼저 판단.

## 문제해결능력 (4유형)

| 유형 | 접근법 | 함정 |
|---|---|---|
| 명제 추론 | 조건을 기호화(p→q), **대우(~q→~p)** 만들어 연결. "어떤/모든"은 벤다이어그램. 참·거짓 문제는 한 명을 참으로 가정 → 모순 찾기 | 역(q→p)을 참으로 착각, "~가 아니면"의 부정 처리 |
| 상황 판단 | 제시된 규정·조건을 **표로 옮기고** 우선순위 순서대로 적용. 예외 조항·단서("다만", "단,") 먼저 체크 | 지문 밖 상식으로 판단, 단서 조항 누락 |
| 자료 해석 | 조건 여러 개로 대상 고르는 유형(업체 선정, 비용 산출 등). **가장 강한 조건(탈락 조건) 먼저** 적용해 후보를 줄인 뒤 계산 | 처음부터 전부 계산하기, 할인·가산 조건 적용 순서 |
| 규칙 적용 | 규칙 읽고 **제시된 예시로 한 번 검증** 후 적용. 코드·암호·순서 배열 유형은 단계마다 메모 | 규칙을 머릿속으로만 처리해 중간 단계 실수 |

- Day 1 의사소통: 위 표의 "접근법"을 풀기 전에 5분만 읽고 시작, 유형 끝나면 "함정" 칸과 오답 대조
