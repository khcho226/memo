# 🎯 ACT

**이번 일요일인 10월 18일 ACT는, 문제풀이 실력보다 평소의 성향과 일하는 방식을 파악하는 인성·컬처핏 검사로 준비하는 게 맞아.** 남은 시간에는 수리·추리 문제집이나 AI 게임 연습보다 **유형 익히기 → 자기 성향 정리 → 응시 환경 점검**이 우선이야.

공식 채용 안내, 2025~2026년 응시·합격 블로그, 링커리어·잡코리아·잡플래닛 자료를 비교했어. **확정 정보와 과거 응시자의 경험을 구분**해서 정리할게.

**1. ACT 개요**
| 항목 | 확인한 내용 |
|---|---|
| 정식 명칭 | **Autoever Culture-fit Test** |
| 평가 목적 | 현대오토에버의 인재가치에 부합하는지 살펴보도록 기존 인성검사를 컬처핏 관점으로 고도화한 검사 |
| 진행 방식 | 온라인 |
| 코딩·과제테스트와의 관계 | **ACT와 별도 전형**이며, 직무에 따라 코딩 또는 과제테스트가 안내됨 |
| 이번 주 준비 방향 | ACT만 안내받았다면 알고리즘·재무 문제풀이 등을 ACT 대비로 할 필요는 없음 |

이 구분은 [현대오토에버 공식 채용 절차](https://career.hyundai-autoever.com/ko/process1)와 [잡플래닛의 2026년 채용 안내](https://www.jobplanet.co.kr/contents/news-8069)에서 확인돼. **게임형 과제나 영상 답변이 포함된 일반적인 ‘AI 역량검사’와 ACT를 같은 시험으로 생각하지 않는 게 중요해.**

다만 ‘전사공통’ 안에서도 세부 직무가 다르므로, **ACT 이후의 과제·면접 구성은 네 지원 공고와 안내 메일이 최우선**이야.

**2. 문항과 시간**
최근 확인 가능한 2025년 직접 응시 후기에서는 **두 파트로 구성되며 각각 약 30~50분**, ‘매우 그렇다/아니다’ 또는 ‘나와 가깝다/멀다’를 선택하는 방식이었다고 설명해. 다만 이는 해당 응시자의 경험이고, 이번 시험의 확정 시간은 아니야. [2025년 ACT 응시·합격 후기](https://mang-kko.tistory.com/133)

과거 잡코리아 후기에는 **여러 문장에 각각 성향 점수를 매기고, 그중 자신과 가장 가까운 것과 먼 것을 고르는 방식**이 등장해. 이런 상대 선택 방식에 익숙해지는 정도는 도움이 되겠지만, 오래된 후기의 문항 수·제한 시간을 그대로 믿으면 안 돼. [잡코리아 응시 후기](https://www.jobkorea.co.kr/starter/Review/view?C_Idx=1611&Ctgr_Code=2&FavorCo_Stat=0&G_ID=0&Page=1)

**이번 회차의 정확한 문항 수·합격선·채점 가중치·전사공통 별도 기준은 공개 자료로 확인하지 못했어.** ‘HMAT와 완전히 같다’거나 ‘몇 퍼센트가 탈락한다’는 말도 공식 확정 정보로 보기는 어려워.

여기서 얻을 수 있는 결론은 **‘무준비면 합격’이 아니라, 정답을 외우는 공부가 핵심은 아니라는 것**이야. 후기만으로 합격 원인을 특정할 수는 없어.

**4. 실전에서 추천하는 응답 원칙**
아래는 공개된 채점 비법이 아니라, 문항을 정확히 이해하고 불필요한 실수를 줄이기 위한 조언이야.

- **평소 모습을 기준으로 답하기:** 가장 잘했던 하루나 최악의 하루보다 최근 학교·직장·팀 활동에서 반복된 행동을 떠올려.
- **‘가장 먼 것’을 ‘나쁜 것’으로 해석하지 않기:** 모두 좋은 문장이어도 상대적으로 덜 해당하는 것을 고르는 질문일 수 있어.
- **표현의 강도를 읽기:** ‘가끔’, ‘대체로’, ‘항상’, ‘절대로’는 다르다. 부정문도 놓치지 마.
- **좋아 보이는 답으로만 채우지 않기:** 모든 항목을 극단적으로 긍정하거나, 반대로 극단 응답을 무조건 피하는 식의 규칙은 권하지 않아.
- **이전 답을 억지로 재현하지 않기:** 일관성은 답을 암기하는 것이 아니라, 같은 자기 기준으로 문장을 읽는 데서 나와.
- **한 문항을 과도하게 분석하지 않기:** ‘회사는 무엇을 원할까’를 추측하기보다 문장 의미와 실제 행동을 비교해 선택해.

예를 들어 **‘새로운 방법을 제안하는 편’과 ‘실행 전에 위험을 검토하는 편’은 동시에 해당할 수 있어.** 도전적인 사람처럼 보이려고 신중함을 모두 부정할 필요는 없어. 이 예시는 실제 출제 문항이 아니야.

**5. 전사공통 지원자로서 정리할 것**
네가 제출한 자기소개서와 **Talent Value 경험 문항**을 다시 읽고, 아래 질문에 짧게 답해봐.

| 점검할 성향 | 스스로 떠올릴 질문 |
|---|---|
| 책임감·주도성 | 문제가 생기면 내가 먼저 확인하고 공유하는가? |
| 협업·소통 | 의견이 다를 때 근거를 설명하는가, 갈등을 피하는가? |
| 정확성·기한 관리 | 검토와 마감이 충돌할 때 실제로 어떻게 처리했는가? |
| 학습·변화 수용 | 새로운 방식이나 피드백에 평소 어떻게 반응하는가? |
| 원칙·기밀 관리 | 편의와 규정이 충돌했을 때 어떤 행동을 했는가? |

이는 **전사공통의 공개 채점 항목이라는 뜻이 아니라 자기 이해를 위한 틀**이야. 회사의 Talent Value도 주도성·도전·문제 해결·성장·협력·상호 인정이라는 방향으로 살펴보면 좋아. 인재상을 외워 성격을 꾸미기보다는, 실제 경험과 연결해 이해하는 용도로 활용해. [Talent Value를 정리한 채용 분석](https://gridresume.com/hiring-analysis/hyundai-autoever)

**6. 남은 이틀 준비**
| 시점 | 추천 준비 |
|---|---|
| **오늘, 30~40분** | 안내 메일 정독. 응시 가능 시간과 실제 검사 제한 시간, 시작 마감과 제출 마감을 구분하고 로그인 확인 |
| **토요일, 40~60분** | 자기 성향 정리 → 공개 인성검사 예시로 척도형·가깝다/멀다 선택 방식만 가볍게 연습 |
| **토요일 저녁, 15분** | 사용할 PC·지원 브라우저·인터넷·충전기 점검. 자동 절전과 예정된 업데이트 확인 |
| **시험 당일** | 종료 직전에 시작하지 말고 충분한 여유 확보. 공식 안내에 따라 검사 완료·제출 상태까지 확인 |

**카메라·마이크·신분증·메모지 허용 여부는 이번 안내문으로 확인해야 해.** 코딩테스트 후기의 준비물이나 감독 규정을 ACT에 그대로 적용하면 안 돼. 검사 중에는 외부 도움이나 AI를 사용하지 말고, 장애 발생 시 안내된 문의 절차를 따라.

**결론적으로, 지금은 비싼 강의나 인적성 문제집을 급하게 살 필요성이 낮아 보여.** 답을 만들어내는 연습보다 **낯선 선택 방식에 익숙해지고, 평소의 자신을 같은 기준으로 판단하며, 집중할 수 있는 상태로 응시하는 것**에 시간을 쓰는 걸 추천해.
